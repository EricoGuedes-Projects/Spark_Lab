# PySpark Laboratory

Projeto criado para estudar PySpark do básico ao avançado.

## Tópicos abordados

- DataFrames
- Transformações
- Ações
- Aggregations
- Spark SQL
- Window Functions
- Joins
- Broadcast Join
- UDF
- Cache
- Persist
- Repartition
- Coalesce
- Explain Plan
- Data Lake
- Parquet

## Execução

Gerar dados:

python scripts/generate_data.py

Executar laboratório:

python scripts/spark_lab.py

Executar consultas:

python scripts/query.py
